Optimization Technique

  • Used Prisma findUnique() because customerId is unique.
  • Used the existing unique index on customerId, allowing PostgreSQL to perform an index scan instead of scanning all 100,000 cart records.
  • Kept the index on restaurantId to improve other cart queries that filter, count, or join carts by restaurant.
Repository Method 
async findCartByCustomerId(
  customerId: number,
  tx?: PrismaTransaction,
) {
  return this.db(tx).cart.findUnique({
    where: {
      customerId,
    },
  });
}
